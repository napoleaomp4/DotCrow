# 0001. Core written in Rust

- **Status:** accepted
- **Date:** 2026-10-19

## Context

DotCrow's core stores API keys, performs cryptography and will execute actions on the owner's computer. Memory errors in this kind of code become security vulnerabilities. We also need small binaries for Windows, macOS and Linux without requiring users to install a runtime.

## Decision

The core (vault, cryptography, router, agents, Ninho and CLI) is written in Rust, in a workspace with one crate per responsibility. Ninho means "nest" in Portuguese and is the local service. `unsafe` is forbidden throughout the workspace.

## Alternatives considered

- **Python:** a great AI ecosystem, but secure distribution without a runtime is difficult, and there are no memory safety guarantees.
- **TypeScript/Node:** fast for prototyping, but the same distribution problem and a large dependency surface.
- **Go:** a good option; Rust won because of its post-quantum cryptography ecosystem (RustCrypto) and control over erasing secrets from memory.

## Consequences

- The learning curve is steeper for contributors unfamiliar with Rust. We offset this with well-described issues and documentation in Portuguese.
- Integrations available only in other languages can be added as external tools called by Ninho, without touching the core.
